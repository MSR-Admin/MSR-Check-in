📱 Google Apps Script Deployment Guide

Complete step-by-step guide to publish and update your web app

🚀 Step 1: Publish New Deployment

Opening the Deployment Menu

  1. Open your Google Apps Script project in the Apps Script editor
  2. Click on "Publish" in the top menu
  3. Select "Deploy from manifest"

Creating the Deployment

  1. In the deployment dialog, click "New deployment"
  2. Click the ⚙️ gear icon next to "Select type"
  3. Choose "Web app"

Deployment Configuration

  1. Description: Enter a description (e.g., "v1.0 - Initial deployment")
  2. Execute as: Select "Me" (your email)
  3. Who has access: Select "Anyone" (this is important!)
  4. Click "Deploy"
⚠️ Important: Make sure to select "Anyone" for "Who has access". If you select "Only myself", the app will require authentication and won't work for visitors.
✓ Success: After deploying, you'll see a web app URL. Copy this URL - it will look like:
https://script.google.com/macros/s/AKfycbXYZ.../exec

🔄 Step 2: Update Code.gs

After making changes to your code:

  1. Make your changes to Code.gs or other files
  2. Save the project (Ctrl+S or Cmd+S)
  3. Go to "Publish" → "Deploy from manifest"
  4. Click the ✏️ pencil icon next to your deployment
  5. Change the version to "New version"
  6. Click "Deploy" again
💡 Tip: Always create a new version when deploying updates. This allows you to roll back if something goes wrong.

🧪 Step 3: Test Your Deployment

Testing the Web App

  1. Open a new browser tab
  2. Paste your web app URL
  3. Press Enter
  4. If you see your app, the deployment is successful!

Testing the API

  1. Add ?action=dashboard to the end of your URL
  2. Press Enter
  3. You should see JSON data if the API is working
https://script.google.com/macros/s/AKfycbXYZ.../exec?action=dashboard

🔧 Step 4: Troubleshooting

Common Issues

  1. 302 Redirect Error: Check if you deployed with "Anyone" access
  2. 500 Internal Error: Check Apps Script execution logs (View → Execution log)
  3. No Data: Make sure your Google Sheet has the correct columns
  4. Wrong Dates: Check date format in Code.gs (should be dd/MM/yyyy)

Checking Execution Logs

  1. In the Apps Script editor, go to "View" → "Execution log"
  2. Look for any red error messages
  3. Check the timestamp to see when the error occurred

✅ Deployment Checklist

  • Code.gs has correct doGet/doPost functions
  • Google Sheet has correct column headers
  • Deployment is set to "Anyone" access
  • Web app URL is copied and working
  • API returns JSON when tested
  • Dates are formatted correctly (dd/MM/yyyy)
  • Admin panel loads without errors
